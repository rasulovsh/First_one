# Claude Limits — виджет лимитов Claude для Windows

Маленькое окошко поверх всех окон, которое показывает:

- **Сессия (5 ч)** — сколько % 5-часового лимита использовано и когда сброс;
- **Неделя** — сколько % недельного лимита использовано и когда сброс.

Полоска зелёная → жёлтая (70%) → красная (90%). Данные обновляются раз в минуту.

## Что нужно

1. **Python 3** для Windows — https://www.python.org/downloads/ (при установке отметьте *Add python.exe to PATH*).
2. **Claude Code**, в который вы вошли своей подпиской Pro/Max (`claude` → `/login`).
   Виджет берёт токен из `%USERPROFILE%\.claude\.credentials.json` — тот же источник, что и команда `/usage`.

## Установка (один раз)

1. Запустите `install.bat`. Он подключает виджет к Claude Code: Claude Code после каждого ответа
   будет передавать виджету свежие лимиты (и показывать их внизу своего окна).
2. Перезапустите Claude Code и отправьте любое сообщение — цифры появятся.

Почему так: сервер, который отдаёт лимиты напрямую (`/api/oauth/usage`), сейчас почти
всегда отвечает **429** — это известная проблема на стороне Anthropic. Поэтому основной
источник — сам Claude Code, а к серверу виджет обращается редко и только как запасной вариант.

## Лимиты из чата и Cowork (рекомендуется)

Лимит у подписки один общий: чат на claude.ai, приложение Claude, Cowork и Claude Code тратят его вместе.
Чтобы виджет обновлялся раз в 2 минуты, где бы вы ни работали, дайте ему ключ сессии claude.ai:

1. Откройте https://claude.ai в Chrome/Edge (вы должны быть залогинены).
2. Нажмите **F12** → вкладка **Application** (Приложение) → слева **Cookies** → `https://claude.ai`.
3. Найдите строку **`sessionKey`** и скопируйте её значение (начинается с `sk-ant-sid…`).
4. В виджете: правая кнопка → **«Ключ claude.ai…»** → вставьте → OK.

⚠️ Этот ключ — это ваш вход в claude.ai. Никому его не отправляйте. Виджет хранит его только у вас,
в файле `%USERPROFILE%\.claude_limits_widget.json`. Если вы выйдете из claude.ai в браузере, ключ
перестанет работать — виджет попросит вставить новый. Чтобы удалить ключ, вставьте пустое поле.

Это та же страница, что «Настройки → Использование» на claude.ai, но официально она для программ не
предназначена, поэтому однажды может перестать работать.

## Запуск

- Двойной клик по `start.bat` (или по `claude_limits.pyw`).
- Чтобы виджет запускался вместе с Windows — один раз запустите `autostart.bat`.

## Управление

- Перетаскивать — левой кнопкой мыши (позиция запоминается).
- Двойной клик — спросить сервер сейчас.
- Правая кнопка — меню: обновить, компактный режим, выход.

## Если пишет «Токен истёк»

Токен входа живёт несколько часов, а продлевает его сам Claude Code. Просто откройте `claude` в терминале — виджет подхватит новый токен при следующем обновлении.

## Если пишет «Ошибка сервера»

- **«Сервер лимитов перегружен (429)»** — запустите `install.bat` (если ещё не запускали) и отправьте сообщение в Claude Code: цифры придут оттуда.
- **«Нет доступа к лимитам» (403)** — токен получен через `claude setup-token`, у него нет прав на лимиты. Войдите обычным способом: `claude` → `/login`.
- Иначе — подробности ошибки записываются в файл `%USERPROFILE%\.claude_limits_widget.log`.
