# VoiceType — голосовой ввод в любое поле

Маленький полупрозрачный виджет, который всегда поверх всех окон.
Ставите курсор в любое поле ввода (браузер, Telegram, Word, чат с Claude…),
нажимаете **F9** или кнопку микрофона и говорите на **русском, английском или узбекском**.
После каждой паузы фраза распознаётся и вставляется туда, где стоит курсор.

```
[ 🎙 ]  AUTO  F9 — говорить   ⏻
  │      │                     └ включить / выключить виджет
  │      └ язык: AUTO → RU → EN → UZ (клик переключает)
  └ клик: начать / остановить запись (серый — ждёт, красный — слушает, жёлтый — распознаёт)
```

* Перетаскивается мышью, позиция запоминается.
* Правый клик открывает меню: язык, режим клавиши, автозагрузка, настройки, выход.
* Клик по виджету **не забирает фокус** у поля ввода (Windows), так что текст попадёт туда, где был курсор.

## Установка (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/) и при установке отметьте **Add python.exe to PATH**.
2. Скачайте папку `voicetype` и дважды кликните **`install.bat`**.
3. При первом запуске скачается модель распознавания (~1,6 ГБ, только один раз).
   Пока она грузится, на виджете написано «Загрузка модели…».

Виджет сам добавится в автозагрузку Windows и будет запускаться вместе с системой.
Отключить автозагрузку можно в меню (правый клик → «Запускать вместе с системой»).
Запустить вручную: `start.bat`.

**macOS:** запустите `install_mac.command`, затем выдайте Python доступ к
«Микрофону», «Универсальному доступу» и «Мониторингу ввода» в Настройках → Конфиденциальность.
На Mac клик по виджету забирает фокус, поэтому там удобнее говорить через F9.

## Нужны ли API-ключи?

**Нет.** По умолчанию всё работает **локально и бесплатно**: модель Whisper
(`large-v3-turbo`) работает прямо на вашем компьютере, без интернета, и звук никуда не уходит.

Если компьютер слабый или нужно быстрее и точнее (особенно для узбекского),
можно включить облачный движок. Откройте `config.json` (правый клик → «Настройки»),
укажите движок и ключ, затем выберите «Перезапустить»:

| `engine` | Что это | Ключ |
|---|---|---|
| `local` | Whisper на вашем ПК, офлайн, бесплатно | не нужен |
| `groq` | Whisper large-v3 в облаке, очень быстро | бесплатный ключ на [console.groq.com](https://console.groq.com/keys) |
| `openai` | `gpt-4o-transcribe`, лучшее качество | платный ключ на [platform.openai.com](https://platform.openai.com/api-keys) |

```json
"engine": "groq",
"api_key": "gsk_...",
```

## Настройки `config.json`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `language` | `auto` | `auto`, `ru`, `en`, `uz` |
| `auto_languages` | `["ru","en","uz"]` | в режиме AUTO выбирать только из этих языков |
| `hotkey` | `<f9>` | горячая клавиша в формате pynput, например `<f8>`, `<ctrl>+<alt>+v` |
| `hotkey_mode` | `toggle` | `toggle`: нажал — говорю, нажал — стоп; `hold`: говорю, пока держу |
| `local_model` | `large-v3-turbo` | `small` для слабых ПК, `large-v3` для лучшего узбекского |
| `device` | `auto` | `cpu` или `cuda` (видеокарта NVIDIA сильно ускоряет) |
| `opacity` | `0.85` | прозрачность виджета (0.3–1.0) |
| `silence_seconds` | `0.9` | какая пауза завершает фразу |
| `min_volume` | `0.006` | порог громкости; поднимите, если шум попадает в текст |

## Советы

* **Узбекский:** в режиме AUTO Whisper иногда путает узбекский с другими языками.
  Если говорите только по-узбекски, переключите язык на **UZ** (клик по надписи языка).
  Текст выводится латиницей.
* Если распознаётся медленно, поставьте `"local_model": "small"` или включите `groq`.
* Лог ошибок лежит в `voicetype.log` рядом с программой.
