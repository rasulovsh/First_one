# VoiceType — голосовой ввод в любое поле

Маленький полупрозрачный виджет, который всегда поверх всех окон.
Ставите курсор в любое поле ввода (браузер, Telegram, Word, чат с Claude…),
нажимаете **F9** или кнопку микрофона и говорите на **русском, английском или узбекском**.
После каждой паузы фраза распознаётся и вставляется туда, где стоит курсор.

```
[ 🎙 ]  AUTO  F9 — говорить   ⏻
  │      │                     └ включить / выключить виджет
  │      └ язык: AUTO → RU → EN → UZ (клик переключает)
  └ клик: начать / остановить запись (серый — ждёт, красный — слушает, жёлтый — распознаёт)
```

* Перетаскивается мышью, позиция запоминается.
* Правый клик открывает меню: язык, режим клавиши, автозагрузка, настройки, выход.
* Клик по виджету **не забирает фокус** у поля ввода (Windows), так что текст попадёт туда, где был курсор.

## Установка на Windows, шаг за шагом

Для установки нужен интернет: скачиваются Python-библиотеки (~300 МБ) и модель (~1,6 ГБ).
Потом программа работает **полностью офлайн**.

### Шаг 1. Установите Python

1. Откройте https://www.python.org/downloads/ и нажмите жёлтую кнопку **Download Python 3.x**.
2. Запустите скачанный файл.
3. **Важно:** внизу первого окна поставьте галочку **«Add python.exe to PATH»**.
4. Нажмите **Install Now** и дождитесь конца установки.

Проверка: нажмите `Win + R`, введите `cmd`, Enter, в чёрном окне наберите `python --version`.
Если видите `Python 3.1x.x`, всё в порядке.

### Шаг 2. Скачайте программу

1. На странице репозитория на GitHub выберите ветку с программой, нажмите зелёную кнопку
   **Code → Download ZIP**.
2. Распакуйте архив туда, где программа будет жить постоянно, например `C:\VoiceType`.
   Не запускайте из папки «Загрузки» или прямо из ZIP: автозагрузка запомнит путь,
   и если потом папку перенести, автозапуск перестанет работать.

### Шаг 3. Запустите установщик

1. Откройте папку `voicetype` и дважды кликните **`install.bat`**.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите
   **Подробнее → Выполнить в любом случае** (это обычный текстовый скрипт, его можно
   открыть Блокнотом и посмотреть).
3. Откроется чёрное окно: создаётся отдельное окружение `.venv` и ставятся библиотеки.
   Это занимает 2–5 минут.
4. В конце окно само запустит виджет. Он появится в правом нижнем углу экрана.

### Шаг 4. Первый запуск: скачивание модели

* На виджете будет написано **«Скачиваю модель…»**: модель Whisper `large-v3-turbo`
  (~1,6 ГБ) сама загружается в папку `voicetype\models`. Это происходит **один раз**.
* Когда кружок микрофона станет тёмно-серым, а справа появится **«F9 — говорить»**, всё готово.
* При следующих запусках модель берётся с диска, интернет не нужен. Без интернета
  программа запускается так же.

### Шаг 5. Разрешите доступ к микрофону

Если запись не начинается: **Параметры → Конфиденциальность и защита → Микрофон** →
включите «Доступ к микрофону» и «Разрешить классическим приложениям доступ к микрофону».

### Шаг 6. Пользуйтесь

1. Кликните в любое поле ввода.
2. Нажмите **F9** (на ноутбуке может понадобиться **Fn + F9**) или кнопку микрофона.
3. Говорите. После паузы текст появится в поле.
4. Ещё раз F9: запись остановится.

### Автозагрузка

При первом запуске виджет сам прописывается в автозагрузку Windows
и дальше стартует вместе с системой. Включить или выключить её можно в меню
(правый клик → «Запускать вместе с системой»).
Запустить вручную: `start.bat`. Закрыть: правый клик → «Выход».

### Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `Python не найден` | переустановите Python с галочкой «Add python.exe to PATH» |
| Долго висит «Скачиваю модель…» | это нормально на медленном интернете (1,6 ГБ); проверьте, что растёт папка `models` |
| Распознаёт медленно | в `config.json` поставьте `"local_model": "small"` или облачный `groq` |
| Текст не вставляется в программу, запущенную от администратора | запустите и VoiceType от администратора |
| Любая другая ошибка | откройте `voicetype.log` в папке программы |

### Как перенести на другой компьютер без интернета

Скопируйте папку `voicetype` целиком вместе с подпапкой `models` после первого запуска.
На новом компьютере нужен только Python и библиотеки (`install.bat`); модель качать не придётся.

### macOS

Запустите `install_mac.command` (правый клик → Открыть). Затем в **Настройки → Конфиденциальность
и безопасность** выдайте Терминалу/Python доступ к «Микрофону», «Универсальному доступу» и
«Мониторингу ввода». На Mac клик по виджету забирает фокус, поэтому говорите через F9.

## Офлайн или онлайн

По умолчанию всё работает **локально и бесплатно**: модель Whisper работает прямо на компьютере.
На обычном ноутбуке без видеокарты NVIDIA это может быть медленно (несколько секунд на фразу и дольше).

Быстрее и точнее: **правый клик → «Онлайн-распознавание и Claude…»**. Выберите движок,
вставьте ключ и нажмите «Сохранить и перезапустить».

| Движок | Что это | Ключ |
|---|---|---|
| **ElevenLabs** | **вживую**: слова печатаются, пока вы говорите (Scribe v2 Realtime) | ключ на [elevenlabs.io](https://elevenlabs.io/app/settings/api-keys) |
| На компьютере | Whisper офлайн, бесплатно | не нужен |
| Groq | Whisper large-v3 в облаке, доля секунды на фразу | бесплатный ключ на [console.groq.com/keys](https://console.groq.com/keys) |
| OpenAI | `gpt-4o-transcribe`, лучше всего со смесью русского и английского | платный ключ на [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |

### Живой режим (ElevenLabs)

Звук идёт на сервер непрерывно, и слова печатаются прямо в поле по ходу речи,
с отставанием примерно в одно слово. Если сервис уточнил слово
(например, расставил запятые в конце фразы), программа сотрёт только то, что сама
напечатала в этой фразе, и впишет исправленный вариант.

* Пока идёт фраза, не переставляйте курсор: исправление сотрёт символы в новом месте.
* В режиме **AUTO** основным языком считается первый из `auto_languages` (по умолчанию `ru`),
  остальные (`en`, `uz`) — дополнительными. Если чаще говорите по-узбекски, поставьте `"uz"` первым.
* С галочкой Claude текст вставляется целой фразой после паузы, а слова видны в пузыре над виджетом.
* `"live_typing": false` — без печати по словам: фраза целиком после паузы, слова в пузыре.

### Узбекский: модель rubaiSTT

Для узбекского можно подключить отдельную модель **rubaiSTT** (`islomov/rubaistt_v2_medium`):
это Whisper medium, дообученный на узбекской речи, в формате whisper.cpp (`ggml-rubaistt.bin`, ~820 МБ).
Работает у вас на компьютере, бесплатно и без интернета.

1. Положите файл в папку `voicetype\models\ggml-rubaistt.bin`, тогда программа найдёт его сама.
   Или укажите путь: правый клик → «Онлайн-распознавание и Claude…» → «Обзор…».
2. Перезапустите виджет.
3. Переключитесь на **UZ** кликом по языку на виджете или клавишей **F8** (F8 переключает UZ ↔ прежний язык).

На **UZ** речь распознаёт rubaiSTT, и фраза вставляется целиком после паузы.
На остальных языках всё как раньше (например, ElevenLabs вживую).

### Исправление текста через Claude

Галочка «Исправлять ошибки и пунктуацию через Claude» отправляет каждую распознанную фразу
в Claude: он исправляет ошибки распознавания и пунктуацию, пишет английские слова латиницей
и ничего не добавляет от себя. Это добавляет 1–2 секунды на фразу.
Нужен ключ Anthropic: [platform.claude.com](https://platform.claude.com/settings/keys)
(это платный API, он оплачивается отдельно от подписки на Claude).
По умолчанию используется `claude-opus-5-5`. Для скорости и экономии в `config.json`
можно поставить `"polish_model": "claude-haiku-4-5"`.

Сам Claude звук не принимает: сначала речь в текст переводит выбранный движок,
и только потом Claude правит готовый текст.

## Настройки `config.json`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `language` | `auto` | `auto`, `ru`, `en`, `uz` |
| `auto_languages` | `["ru","en","uz"]` | в режиме AUTO выбирать только из этих языков |
| `hotkey` | `<f9>` | горячая клавиша в формате pynput, например `<f8>`, `<ctrl>+<alt>+v` |
| `hotkey_mode` | `toggle` | `toggle`: нажал — говорю, нажал — стоп; `hold`: говорю, пока держу |
| `local_model` | `large-v3-turbo` | `small` для слабых ПК, `large-v3` для лучшего узбекского |
| `device` | `auto` | `cpu` или `cuda` (видеокарта NVIDIA сильно ускоряет) |
| `beam_size` | `1` | `5` точнее, но медленнее (только для движка на компьютере) |
| `polish` | `false` | исправлять текст через Claude |
| `polish_model` | `claude-opus-5-5` | модель Claude для исправления |
| `live_silence_seconds` | `0.6` | пауза, после которой ElevenLabs закрывает фразу (0.3–3) |
| `live_typing` | `true` | печатать слова вживую (ElevenLabs) |
| `insert_method` | `type` | `type` — печатать текст, `paste` — вставлять через буфер обмена |
| `uz_model_path` | `""` | путь к узбекской модели whisper.cpp (.bin) |
| `uz_hotkey` | `<f8>` | клавиша переключения UZ ↔ прежний язык |
| `opacity` | `0.85` | прозрачность виджета (0.3–1.0) |
| `silence_seconds` | `0.9` | какая пауза завершает фразу |
| `min_volume` | `0.006` | порог громкости; поднимите, если шум попадает в текст |

## Советы

* **Узбекский:** в режиме AUTO Whisper иногда путает узбекский с другими языками.
  Если говорите только по-узбекски, переключите язык на **UZ** (клик по надписи языка).
  Текст выводится латиницей.
* Если распознаётся медленно, поставьте `"local_model": "small"` или включите `groq`.
* Лог ошибок лежит в `voicetype.log` рядом с программой.
